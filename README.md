# Tanban board

Its a kanban board clone build with react and Tsx, where everything stores in your browser. You can add drag adn delete cards. Column can also be added and deleted.

## How to use 

You can add wia buttons with add name on them. Delete with X. Reset the whole board to seed by clicking "Reset Board". By clicking and dragging a card you can change its positions and even go to other columns. All of this is built on local storage so dont delete your cache if you dont want lost data. 
## Features

- Add and delete a card or column 
- Rename title
- Drag and drops on cards
- Local storage save cards
- reset button
- starting seed

## Tech
React, TypeScript, Vite, @dnd-kit, plain CSS, built in WebStorm

## How to start 
```bash
git clone https://github.com/Tretaq/tanban-board
cd tanban-board
npm install
npm run dev
```
